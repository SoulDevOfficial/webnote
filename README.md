# What is this project?
This is a small little project I did randomly after getting frustrated with apple notes not having features and customization I wanted along with everything else seemingly being filled with AI. I wanted privacy. My data on my device, easily customizable, easily exportable.

To be clear, webnote is not fully secure as it uses your website history as a way to store your information. The best way would be to have an app / program on your device. Though it would be great to release something like it on mobile, there are various hurtles that I simply don't have the money or time to handle. As for releasing it on windows, that is something I'm looking into!
